## 🎨 Filosofi Desain & Karakteristik

Setiap template di BioBlogger dirancang dengan 4 prinsip fundamental:
1. **Lightweight & Zero-Bloat**: Dihasilkan dalam bentuk HTML5 semantik dan CSS murni tanpa runtime JavaScript berat di halaman pengunjung.
2. **Platform Native Aesthetics**: Tombol platform populer (GitHub, WhatsApp, Instagram, Spotify, dll) menggunakan warna merek resmi dan ikon SVG teroptimasi.
3. **Engaging Micro-interactions**: Animasi *hover* (Scale, Shift, Glow) menghidupkan interaksi pengguna di desktop maupun mobile.
4. **100% Responsive & Safe Notch**: Disesuaikan untuk seluruh rasio layar smartphone modern dari iPhone dengan Dynamic Island hingga layar Android lebar.

## 🚀 Cara Menggunakan Template Showcase di Aplikasi

1. Buka aplikasi BioBlogger di browser Anda.
2. Klik tombol **"Showcase"** di navigasi kanan atas atau buka rute `#/showcase`.
3. Telusuri katalog template berdasarkan kategori pilihan Anda (*Tech, Creator, Bisnis, Musik, Minimal*).
4. Klik tombol **"Gunakan"** pada template yang Anda inginkan.
5. Template akan otomatis terpasang ke editor Anda secara instan:
   - Nama profil, bio, dan foto sampel terisi.
   - Daftar link sampel beserta warna dan ikon resmi langsung muncul.
   - Tema, warna tombol, dan efek hover langsung aktif.
6. Anda cukup mengganti nama, tautan URL, dan foto dengan data asli Anda.
7. Klik **Export XML Blogger** atau **Export HTML** untuk mempublikasikannya!

## ⚡ Pengoptimalan Core Web Vitals & SEO

Setiap kode yang dihasilkan oleh generator BioBlogger mengikuti standar web modern:
- **Largest Contentful Paint (LCP):** Gambar avatar dimuat dengan atribut `loading="eager"` dan `fetchpriority="high"`.
- **Cumulative Layout Shift (CLS):** Semua elemen tombol dan avatar memiliki dimensi eksplisit (`width="96"` `height="96"`).
- **First Input Delay (FID) / INP:** 0 ms karena tidak ada skrip blocking JavaScript yang dieksekusi saat pengunjung mengakses halaman akhir Anda.
- **A11y (Accessibility):** Semua tautan dilengkapi atribut `aria-label` deskriptif untuk pembaca layar (*screen reader*).
